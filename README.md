# Summer-MUD
OUC summer mud game dev
OUC夏季学期程序设计基础实践项目

Summer-MUD 是一款基于 C++ 面向对象程序设计开发的文字类 MUD 游戏。项目以“中国式高三生活模拟”为主题，玩家扮演一名高三学生，在30天的高中最后一月中，通过学习、休息、娱乐、社交、购物等选择改变自身属性，最终参加高考并产生不同人生结局。
游戏核心思想：玩家不是通过战斗升级，而是通过人生选择进行成长。不同的选择会影响智力、情商、健康、压力、学科能力以及最终高考结果。

主要对象：
1. Player：表示玩家角色。
基础属性，金钱，物品，当前状态
2. Stats：保存玩家核心属性。
健康值、压力值、智商值、金钱、（科目熟练度）
3. GameManager：负责游戏整体调度。
 开始循环  ->  五天学习,一天考试,一天周末  ->  玩家选择  ->  行动  ->  事件  ->  考试
4. Event：表示游戏事件。
后续增加
5. Action：表示玩家行为
学习、休息、娱乐、社交、购物、运动。

初始行动点：
上午->2,下午->2,晚上->1
行动点：
2上午{认真听课，上课睡觉，（玩手机），（玩mp4），（看小说），自习，吃零食}
1中午{睡午觉、自习、玩手机、玩mp4}
2下午{认真听课，上课睡觉，（玩手机），（玩mp4），（看小说），自习，吃零食}
0晚上{地点列表：1、图书馆2、体育馆3、游戏厅4、商店5、家}

周六考试，周天放假。
6. Item：表示游戏物品。
手机，紫色内裤，五三教辅，网课，零食，小说，mp3，三国杀7. Exam：负责考试计算。8. SaveManager：负责存档管理。
7. TimeManager：负责时间计算。
