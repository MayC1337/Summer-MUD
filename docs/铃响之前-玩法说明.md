# 铃响之前

高考倒计时35天。一段关于成绩、同桌、家人和告别的文字校园故事。

## 一天怎样度过

不再选择每日目标。晨间直接进行晨读、吃早餐、散步或梳理弱科；午间以午饭、休息和交流为主；下午进入课堂或专项练习；夜晚可以去图书馆、体育馆、游戏厅、商店或回家。每日结束只显示简短状态和最近周测成绩，完整属性仍可输入「状态」查看。学科能力满值100，与考试卷面分不同。

四个时段有不同的Q版字符画。低体力时人物打瞌睡，高压力时人物冒汗。启动时显示符号拼成的中文大标题、逐行动画与倒计时进度条。

普通行动可以沿用上一个学习日的选择与晚间活动地点，这些信息也会随存档恢复。故事和每周大事仍需手动选择。物品不足时会重新询问选择。

## 地图与人物

输入 `map/地图` 查看9个地点的连通关系，`look/观察` 查看所在地点和出口，`who/人物` 查看当前人物。晚间主菜单可以输入 `north/south/east/west` 或 `北/南/东/西` 沿相邻出口移动；移动本身不消耗行动，选6才执行当地活动。原来的1—5地点选项仍可使用，并显示自动寻路路线。

NPC包括林晓、班主任、门卫、家人、店主和图书馆管理员。每个时段开始、方向移动或选择目的地到达时自动提示现场人物与交谈示例；晚间主菜单和地图同时列出当前时段各地点的人物。输入 `talk 林晓` 或 `交谈 林晓` 对话，部分台词会根据此前的故事选择变化。与同一人物一天只获得一次压力-1的收益，读档不能重复领取。

`status/状态`、`inventory/背包`、`time/时间` 和 `help/帮助` 可在选择时使用，不消耗行动。

## 学习与周测

补基础适合薄弱科；整理错题兼顾理解能力，智力达到60和80时周考随机波动依次缩小；挑战难题有失败可能，学科能力达到70时成功率由35%提高到65%。学科达到60、80、90后收益逐级递减。

每日目标的选择和完成日记均已移除；旧存档字段仅用于兼容，不影响玩法。月初心愿仍会存档并在最终报告中核对。

每周六（第6、13、20、27、34天）自动周测，共5次。显示各科分数、750分总分、相较上周的变化和按得分率判断的薄弱科目。看完输入1继续，可在成绩单处保存退出，读档不会重复结算这次周测。

## 故事与每周主题

四条连续故事各四段：林晓的错题本、班主任的便签、家人的夜宵、流浪猫橘子。选择影响即时数值与下一段对话，并用于生成结局回忆。每段只触发一次。旧存档未经历的故事会按前置顺序补发，每时段最多一段。

每周开头依次经历写下心愿、小组挑战、模考动员、毕业照与留言册、整理书桌。五场周考各有不同旁白。

## 结局与存档

考试满分750，语数英各150、理综300。结局包含成绩、模拟大学去向、具名通知书、四条故事的告别回忆和角色留言。中国海洋大学去向有专属向海旁白。大学区间为游戏设定。

使用V4存档并兼容读取V1/V2/V3。每个阶段完成后自动保存，也可以在任何游戏选择处输入 `save/存档` 或 `quit/退出`。退出不再推进一天，未完成的菜单、当前地点和待选择的随机事件都能恢复。若保存失败，程序会保留旧存档并取消主动退出；输入流结束时会停止推进并尝试保存。结局输入0再回车退出。

## 编译与验证

CMake目标仍名为Summer-MUD，最终程序统一为build/铃响之前.exe。旧版本与重复程序已清理，请用这一文件启动游戏。

测试源文件：tests/StoryIntegration.cpp。将它与src下除main.cpp之外的实现文件一同编译，并在临时目录执行，避免测试存档混入游玩目录。
